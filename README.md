# Line of Flight's Homebrew tap

```sh
brew install lineofflight/tap/canape
```

`canape` is the command-line tool and MCP server for [Canape](https://cana.pe), a personal reference library. Homebrew updates it with `brew upgrade`. The same notarized release installs without Homebrew with `curl -fsSL https://cana.pe/install | sh`.
